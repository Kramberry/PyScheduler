# ShiftDesk - Weekly Scheduler

## What this is
Flask app that lets a boss build weekly work schedules and export to PDF/Excel.

## Stack
- Python/Flask backend
- Tailwind CSS frontend
- JSON files for data persistence (employees.json, last_schedule.json)
